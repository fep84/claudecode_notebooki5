# Escalas das classes da Escola Sabatina (classes-es)

Código da escala de responsáveis por classe, publicado em `iasdgloria.com.br/escalas/classes-es/`.
A primeira classe é `vivendo-o-reino/`. Esta pasta espelha o que está no servidor, dentro de `/escalas/`.

## Cuidados

- `vivendo-o-reino/api/config.php` aqui tem a `sessao_secreta` trocada por um texto de exemplo. A chave verdadeira fica só no servidor. Não suba este config.php por cima do que está no servidor.
- `escalas.json`, `professores.json` e `usuarios.json` aqui são os arquivos iniciais (vazios). Os dados reais são editados pelo site e ficam só no servidor. Nunca suba esses arquivos por FTP depois que a escala estiver no ar.
- As pastas `fotos/`, `cache/`, `backups/` e o arquivo `log.ndjson` são gerados no servidor.

## Lições

`vivendo-o-reino/licoes/2026-04.json` e `licoes/2026-04/01.jpg` a `13.jpg` são as lições e ilustrações do 4º trimestre de 2026. Um novo trimestre precisa de um novo pacote de lições e de uma nova `capa-trimestre.jpg`.
